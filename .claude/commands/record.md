기록 문서 셋(`docs/PROGRESS.md` · `docs/DECISIONS.md` · `docs/tools.md`)을 갱신한다.

⚠ **직접 고치지 마라.** 이 셋은 `record` 에이전트의 몫이다.
네 몫은 **근거를 모아 지시문을 조립하고, 에이전트를 태우고, 결과를 검증해 보고**하는 것이다.

## 1. 근거 모으기

- `git log --oneline -20` · `git status --short` · `git diff --stat`으로 범위를 잡는다.
- `$ARGUMENTS`에 「커밋분만」·「HEAD 기준」이 있으면 미커밋 목록을 **제외 대상으로 명시**한다.
- **이 대화에서 나온 것 중 diff에 안 보이는 것**을 모은다 — 에이전트는 이 대화를 못 본다.
  - 사용자가 정한 것(원문을 짧게 인용) → `[사용자]` 결정 후보
  - 내가 구현하며 정한 것 → `[에이전트]` 결정 후보
  - 아직 안 정해진 것 → 열린 결정
  - 이번에 겪은 실수 중 되풀이될 것 → 교훈 후보
  - 사용자가 직접 해야 하는 일

## 2. 에이전트 태우기

`record` 에이전트를 부른다. 지시문에 위 근거를 **전부** 적는다 — 「아까 그것」 같은 말은 통하지 않는다.

## 3. 검증

- `git diff -- docs/PROGRESS.md docs/DECISIONS.md docs/tools.md`로 바뀐 것을 직접 읽는다.
- `[사용자]` 표지가 붙은 결정이 정말 사용자가 정한 것인지 대화와 대조한다.
- 담당 셋 밖이 바뀌었으면 되돌리고 보고한다.

## 4. 보고
