# launcher — 원클릭 실행기

프로젝트 폴더의 **`run_dashboard.bat` 더블클릭 한 번**으로 첫 실행부터 대시보드까지 연다. 터미널 명령을 치지 않는다(D-33) [사용자].
bat은 「uv 준비 → 부품 설치」까지만 하고, 나머지는 파이썬(`agent/launcher.py`)이 한다 — bat 문법은 한글·분기에 약하다.

## 구성요소

```text
run_dashboard.bat                       # 저장소 뿌리. 창 제목 · uv 준비 · uv sync · uv run python -m agent.launcher
```

```python
def ensure_env(root: Path) -> bool                              # .env가 없으면 .env.example을 복사(값은 비어 있음). 만들었으면 True
def server_running(port: int) -> bool                           # 이미 켜진 우리 서버인가(/api/status가 응답하나)
def main() -> int                                               # 전체 흐름
```

## 동작

### `run_dashboard.bat`

1. 글자판을 UTF-8로(`chcp 65001`) 바꾼 **뒤** 창 제목을 「유튜브 댓글 에이전트 — 이 창을 닫으면 종료돼요」로. 작업 폴더를 bat이 있는 폴더로.
2. **크롬이 있는지 먼저 본다**(Program Files · Program Files (x86) · 사용자 AppData). 없으면 「구글 크롬이 필요해요」를 보여 주고 멈춘다 — 부품 설치(1~2분)를 기다린 뒤에야 알게 되지 않게.
3. **uv가 없으면 자동 설치** [사용자] — uv 공식 설치 스크립트(`https://astral.sh/uv/install.ps1`)를 PowerShell로 실행하고, 이번 창의 경로에 설치 폴더를 더한다. 설치가 실패하면 이유를 보여 주고 멈춘다(`pause`).
4. `uv sync` — 부품 설치(첫 실행만 1~2분, 파이썬도 uv가 받는다). 실패하면 멈춘다.
5. `uv run python -m agent.launcher`.

### `launcher.main`

1. 크롬을 찾는다(bat과 같은 자리). 없으면 멈춘다 — 대시보드 열기에 쓴다.
2. `.env`가 없으면 빈 `.env`를 만든다. 키 안내는 대시보드가 한다(D-28).
3. 설정(`config.yaml`)을 읽어 본다 — 잘못됐으면 이유를 보여 주고 멈춘다. **바탕화면 바로가기는 만들지 않는다 [사용자]** — 프로필 크롬은 대시보드의 [프로필 관리]에서 연다(`open_profile_window`, dashboard 명세). 예전에 만든 바로가기는 지우지 않는다.
4. 포트 8501에 **이미 우리 서버가 켜져 있으면** 대시보드 페이지만 크롬으로 열고 끝낸다(창이 닫힌다).
   다른 프로그램이 그 포트를 쓰고 있으면 이유를 보여 주고 멈춘다.
5. 서버(uvicorn `app:app`, 127.0.0.1:8501)를 켠다. 서버가 응답하면 크롬으로 `http://localhost:8501`을 열고, 이 창을 **최소화**한다 [사용자].
6. 창을 닫으면 서버가 끝난다.

- 서버는 이 컴퓨터에서만 접속된다(`127.0.0.1`) — 다른 기기에서 내 게시 로봇을 부르지 못하게.
- 대시보드는 평소 크롬(기본 프로필)으로 연다. 게시용 프로필 창과는 별개다.
- 멈출 때는 언제나 이유를 보여 주고 키 입력을 기다린다 — 창이 번쩍 닫혀 이유를 못 보는 일이 없게.
- 창을 닫으면 서버는 끝나지만, 그때 하던 게시 한 건은 게시 로봇이 따로 끝까지 마친다(dashboard 명세) [사용자].
- 최소화가 안 되는 창(Windows 터미널 앱이 창을 맡는 경우)이면 그냥 둔다 — 수동 확인에서 본다.

## 정체성

- `.env`는 없을 때만 만들고 있는 파일은 건드리지 않는다 — `기능_실행기_env가_있으면_건드리지_않는다`
- 크롬 찾기 · 프로필 창 열기 · 로그인 확인은 chrome 명세가 진다(실행기는 `chrome.find_chrome`을 쓴다).

## 테스트 방법

- 단위 테스트는 `.env` 만들기만 본다. 서버 켜기 · bat은 수동 확인.
- 수동 확인: ① uv가 있는 지금 PC에서 더블클릭 → 대시보드가 열리고 창이 최소화 ② 한 번 더 더블클릭 → 페이지만 열림 ③ 대시보드 [프로필 관리]에서 [크롬 열기] → 그 프로필 크롬 창이 유튜브로 열림.
  uv가 없는 PC에서의 자동 설치는 이 PC에서 확인할 수 없다 — 보고에 밝힌다.
