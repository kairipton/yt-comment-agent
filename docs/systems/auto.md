# auto — 자동 모드

`post_mode: auto`일 때 목록에서 **체크한 여러 영상**을 사람 승인 없이 **차례로** 초안 → 문지기 → 게시까지 돌린다(D-25 [사용자]).
사람 검토가 없으므로 안전장치는 문지기와 게시 검사(`poster.check_post`)뿐이다 — 자동 모드도 ③ 한 번 누름과 **같은 게시 경로**를 탄다.

## 구성요소

```python
class AutoItem:                                   # 영상 하나의 차례: id · 제목 · 상태 · 이유 · 시도 id
class AutoJob:                                    # 한 번의 자동 실행: 차례 목록 · 멈춤 신호 · 지금 상태(화면용 snapshot)
    def snapshot(self) -> dict
    def stop(self) -> None                         # 지금 하던 영상까지만 하고 멈춘다
@dataclass(frozen=True)
class AutoDeps:                                   # 자동 실행이 쓰는 일. 서버가 진짜를, 테스트가 가짜를 넣는다
    open_store: Callable[[], tuple[Settings, Store]]
    write_draft: Callable[[Settings, Store, VideoItem], Draft]   # 저장된 초안이 없으면 쓴다(서버 ②와 같은 함수)
    begin_post: Callable[[Settings, Store, VideoItem, str], int]  # 시도 생성 → check_post → 로봇 띄우기 or 거부(서버 ③과 같은 함수)
    pick_profile: Callable[[Settings, Store], str]              # 배정 방식대로 프로필(직접 고르기면 고른 것, 자동이면 next_profile)
    wait_post: Callable[[int], Attempt]                          # 그 누름이 끝날 때까지 기다려 마지막 줄
    wait: Callable[[float], bool]                                # 간격 기다리기. 멈춤 신호가 오면 True
def run_auto(job: AutoJob, deps: AutoDeps) -> None              # 차례대로 돈다(서버가 뒤에서 한 줄기로 돌린다)
```

## 동작

### 한 영상의 차례

1. **멈춤 확인** — [멈추기]가 눌렸으면 남은 차례는 「멈춤」으로 끝낸다.
2. **하루 상한 확인** — `guard.check_quota`로 오늘 수(`guard.quota_window` 구간)가 상한이면 남은 차례를 「오늘 상한에 닿아 멈췄어요」로 끝내고 **전체를 멈춘다**(D-25).
3. **초안** — 저장된 초안이 있으면 그것, 없으면 쓴다. 실패하면 이 영상은 「실패」+이유, 다음 영상으로.
4. **게시** — 프로필을 정하고(`pick_profile`) `begin_post`. 게시 검사에 걸리면(불합격 초안 · 허용 범위 밖 · 이미 단 영상 등) 이 영상은 「건너뜀」+이유, 다음 영상으로 — 로봇을 띄우지 않았으니 간격도 두지 않는다.
5. **기다림** — 로봇이 끝날 때까지 기다려 결과(완료 · 실패)를 차례에 적는다. 재시도(D-12)는 로봇 안에서 일어난다.
6. **간격** — 실제로 로봇을 띄운 영상 뒤, 남은 차례가 있으면 `auto.gap_seconds`만큼 기다린다(그 사이 [멈추기]를 누르면 바로 멈춘다).

### 실행과 상태

- 자동 실행은 **한 번에 하나** — 돌고 있으면 새로 시작하지 않는다(409). 게시 로봇의 잠금과 별개로, 자동 실행끼리도 겹치지 않게.
- 서버가 뒤에서 한 줄기(스레드)로 돌린다. 서버 창을 닫으면 자동 실행은 멈춘다 — 그때 하던 게시 한 건은 로봇이 끝까지 마친다(dashboard 명세 [사용자]).
- 차례 상태: 대기 · 초안 쓰는 중 · 게시 중 · 게시 완료 · 건너뜀 · 실패 · 멈춤.
- 예상 못 한 오류는 삼키지 않는다 — `logging.error` 후 그 영상은 「실패」, 다음 영상으로.
- 영상 처리 밖(차례 사이 — 설정 다시 읽기 · 하루 수 세기)에서 오류가 나면 `logging.error` 후 남은 차례를 「실패 — 자동 실행이 오류로 멈췄어요」로 끝내고 멈춘다 — `기능_자동모드_차례_사이_오류는_남은_차례에_이유를_남긴다`

### 서버 · 화면

| 경로 | 하는 일 |
|---|---|
| `POST /api/auto {video_ids, profile}` | 자동 실행 시작. `post_mode`가 `auto`가 아니면 409 · AI 키가 없으면 409 · 이미 돌고 있으면 409 · 모르는 영상이면 404 |
| `GET /api/auto` | 지금(또는 마지막) 자동 실행의 상태 — 차례마다 상태·이유·댓글 링크, 끝났나 |
| `POST /api/auto/stop` | 지금 하던 영상까지만 하고 멈춤 |

- 화면(`post_mode: auto`일 때만): ① 목록의 영상마다 체크칸(게시 대상인 영상만 켜짐) · ③에 [체크한 영상 n개 자동으로 달기] · [멈추기] · 차례 목록(상태 아이콘 + 이유 + 댓글 보기). 1초마다 상태를 묻는다.
- `post_mode: manual`이면 체크칸·자동 버튼이 보이지 않는다.

## 정체성

- 체크한 영상을 차례로 게시하고, 실제로 게시한 영상 사이에만 간격을 둔다 — `기능_자동모드_차례로_게시하고_사이에만_간격을_둔다`
- 하루 상한에 닿으면 남은 차례를 멈춘다 — `기능_자동모드_하루상한에_닿으면_멈춘다`
- 게시 검사에 걸린 영상은 건너뛰고 다음으로 간다 — `기능_자동모드_검사에_걸리면_건너뛰고_계속한다`
- [멈추기]를 누르면 남은 차례를 시작하지 않는다 — `기능_자동모드_멈추면_남은_차례는_멈춤이다`
- 초안을 못 쓰면 그 영상만 실패하고 다음으로 간다 — `기능_자동모드_초안을_못쓰면_그_영상만_실패한다`
- 수동 모드에서는 자동 실행을 시작하지 않는다 — `예외_서버_수동모드면_자동실행을_거부한다`
- 자동 실행은 한 번에 하나다 — `예외_서버_자동실행이_돌고있으면_새로_시작하지_않는다`
- 자동 실행은 승인 없이 초안을 쓰고 ③과 같은 게시 경로로 로봇을 띄운다 — `기능_서버_자동실행은_초안을_쓰고_같은_게시경로로_로봇을_띄운다`

## 테스트 방법

- `run_auto`에 가짜 `AutoDeps`를 넣어 차례 순서 · 간격 · 상한 멈춤 · 건너뜀 · 멈춤을 본다(스레드 없이 바로 부른다). 서버 테스트는 가짜 YouTube·작가·로봇.
- 수동 확인: `post_mode: auto`로 바꾸고 테스트 영상을 체크해 실행 → 초안 → 게시 → 완료가 차례 목록에 보임. 지정 채널 영상은 체크칸이 꺼져 있음(채널 게시 꺼짐).
