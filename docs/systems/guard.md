# guard — 문지기

게시해도 되는지, 댓글이 규칙을 지키는지 **판정만** 한다. 결정론 부품이다 — 같은 입력이면 언제나 같은 판정(D-19).
필요한 값(오늘 게시 수 · 현재 시각 · 설정)은 전부 인자로 받는다. 입출력·현재 시각 읽기·난수·다른 부품(store 등) import 금지 — `tests/test_architecture.py`가 강제한다.
불합격이면 `Verdict.reasons`에 **이유를 전부** 담는다. 작가(draft)가 그 이유를 붙여 다시 쓰고, 화면이 그대로 보여 준다.

## 구성요소

## 동작

### 허용 범위 — `check_target`

순서대로 본다.
1. 출처가 `RISING`(뜨기 직전)이면 거부 — 「뜨기 직전 영상은 초안까지만」. 지정 채널 영상이어도 거부한다(D-22).
2. 영상 id가 테스트 영상 목록에 있으면 통과.
3. 채널 id가 지정 채널 목록에 있으면: `channel_posting`이 켜져 있을 때만 통과, 꺼져 있으면 거부 — 「지정 채널 게시가 꺼져 있어요」(D-34) [사용자].
4. 나머지는 거부 — 「허용 채널이 아님」. 링크로 들어온 영상도 여기서 걸린다.

### 영상당 1개 · 하루 상한 — `is_exempt` · `check_quota`

- `is_exempt` = `dev_mode`가 켜져 있고 테스트 영상일 때만 참(D-17 · D-23).
- `check_exempt(claimed, allowed)`: 시도 줄에 예외로 적혔는데(`claimed`) 지금 `is_exempt`가 거짓이면(`allowed`) 거부 — `dev_mode`를 켜고 만든 줄을 끈 뒤 띄우는 경우.
- `check_quota`는 두 가지를 **둘 다** 보고 이유를 모은다:
  - `submitted_today >= daily_max` → 「오늘 상한 N개에 도달」. 예외 영상에도 적용한다.
  - `already_posted`이고 예외가 아니면 → 「이미 댓글을 단 영상」.

### 초안 일치 — `check_draft` (poster 명세)

- 초안이 없거나 · `issues`가 있거나 · 글이 초안 댓글과 다르면(앞뒤 공백 무시) 거부. **모드와 무관** — 자동 모드·로봇 직접 실행으로 불합격 초안이 새지 않게.

### 글자 수 — `char_count` (D-21)

- `no_spaces`: 공백 문자(스페이스·줄바꿈·탭)를 뺀 글자 수. `with_spaces`: 전체 글자 수.

### 댓글 규칙 — `check_text` · `check_comment`

아래를 **모두** 검사하고 걸린 것을 전부 이유로 담는다. `check_text`는 「재료와 겹침」을 뺀 나머지 전부, `check_comment`는 `check_text` + 「재료와 겹침」이다.
게시 로봇은 재료(자막)를 다시 받지 않으므로 `check_text`로 다시 본다(poster 명세).

| 검사 | 기준 | 값의 주인 |
|---|---|---|
| 하한 | `char_count(text, min_count) >= min_chars` | config |
| 상한 | `char_count(text, max_count) <= max_chars` | config |
| 링크 | `http://` · `https://` · `www.` · `youtu.be` · 도메인 꼴(`.com` · `.net` · `.kr` · `.co` · `.io` · `.me` · `.ly`) | 이 문서 |
| 해시태그 | `#` 또는 전각 `＃` 바로 뒤에 글자 | 이 문서 |
| 브랜드 | `brand`(운명원)가 들어 있다 | config |
| 지어낸 후기 | ① `forbidden_phrases`의 표현이 하나라도 들어 있으면 거부 — 단 **남의 경험을 전해 들은 말 속이면 통과**(아래, ②와 같은 판단) [사용자]. ② **브랜드 바로 곁의 「직접 겪은」 표현**이면 거부 — 브랜드가 나온 자리의 뒤 30글자 · 앞 12글자에서 찾는다(아래) [사용자] | config · 코드 |
| 재료와 겹침 | 댓글의 **세 글자 조각**(아래) 중 재료(`source_text` = 자막·제목·설명. 인기 댓글은 넣지 않는다)에도 있는 것이 `grounding_min_overlap`개 이상 | config |
| 다른 글과 비슷함 | `others` 각각과 세 글자 조각 집합의 자카드 유사도(겹친 조각 수 ÷ 합친 조각 수)가 `max_similarity` 이하 | config |

**세 글자 조각:** 띄어쓰기로 나눈 낱말마다, 한글만 남겨 붙은 세 글자씩 잘라 낸 것(「바빠서라니」→ 바빠서 · 빠서라 · 서라니).
브랜드(`brand`)와 브랜드 소개(`brand_desc`)에서 나오는 조각은 빼고 센다 — 모든 댓글에 공통으로 들어가 겹침·유사도를 부풀리기 때문이다.
두 글자 조각은 「연애」「진짜」처럼 이 채널들의 재료에 늘 있는 말로 쉽게 채워져 쓰지 않는다 [에이전트].

- 「재료와 겹침」은 장면 언급을 **보증하지 않는다** — 재료와 동떨어진 초안을 거르는 최소선이다. 장면 언급의 본체는 작가의 지시문이다. 거르는 힘은 2단계에서 실제 초안으로 잰다.
- 「지어낸 후기」 ②(브랜드 곁 경험 표현) [사용자: 「후기 검사만 좀 하자」 — 패턴 검사 방식]: 표현 목록만으로는 「운명원 가봤는데 딱 맞더라고요」가 통과했다(실측). 그래서 브랜드가 나온 자리마다 **뒤 30글자**에서 직접 겪은 말(가봤 · 갔었 · 갔을 · 가서 · 다녀 · 들렀 · 방문 · 예약했 · 상담 받 · 봐 줬 · 해 준(해 준다 제외) · 말씀하신 · 봤는데 · 받았 · 맞더라 · 맞혔 · 소름 · 덕분에 · 단골 · 「에서 들은」 등)을, **앞 12글자**에서 겪은 것을 꾸미는 말(다녀온 · 갔던 · 가 본 · 단골 등)을 찾는다. 「추천 받았」 · 「검색해 봤는데」 · 「찾아 봤는데」는 이용한 것이 아니라 뺀다. **남이 겪은 일을 전해 들은 말은 통과** — 앞에 남을 가리키는 주어(친구가 · 언니가 · 지인이 · 사람들이 …)가 있고 뒤가 전해 들은 끝맺음(~대요 · ~래요 · ~다던데 · ~다더라 · ~다고 했 …)이면, 또는 경험 표현이 남을 꾸미는 꼴(「운명원 다녀온 지인이」)이면 그 자리는 보지 않는다. 남을 가리키는 주어는 그 자리 앞 25글자 안(앞 문장으로 넘어가지 않음)에서 찾는다. **이 「전해 들은 말」 판단은 ①의 표현 목록에도 똑같이 쓴다** [사용자: 「설정의 금지 표현 목록에도 남의 경험을 전해 들은 말은 통과시키는 예외를 적용해 줘」] — 「친구가 운명원 다녀왔는데 잘 본대요」의 「다녀왔」은 막지 않는다. 판단 함수는 하나다. 표현 묶음은 규칙의 일부라 코드(`guard`)에 둔다 — 링크 · 해시태그 꼴과 같다. 거부 이유에는 걸린 부분을 그대로 보여 준다. 그래도 목록 밖 표현은 작가의 지시문이 맡는다.
- 전해 들은 말투(「잘 본다던데」)는 허용이다.

### 재시도 — `can_retry` (D-12)

- 참인 경우는 하나뿐: 상태가 `FAILED_BEFORE_SUBMIT`이고 `retry_no < max_retries`이고 취소(`cancelled` — 사용자가 크롬 창을 닫음)가 아닐 때 [사용자].
- 횟수는 **③을 한 번 누를 때마다** 새로 센다 — 첫 시도가 `retry_no=0`, 자동 재시도가 1·2. 그래서 한 번 누르면 최대 3번 시도한다 [사용자].
  사람이 ③을 다시 누르면 새로 센다.
- 게시 버튼 뒤 실패(`FAILED_AFTER_SUBMIT`)는 재시도하지 않는다 — 같은 영상에 댓글이 둘 달릴 수 있다.

### 링크에서 영상 id — `parse_video_id`

- 받는 꼴: `youtu.be/<id>` · `youtube.com/watch?v=<id>`(다른 쿼리가 섞여도) · `youtube.com/shorts/<id>` · `youtube.com/live/<id>` · `youtube.com/embed/<id>` · `m.` · `www.` · `music.` 붙은 주소 · `http(s)://` 없이 · 영상 id 11자만.
- 영상 id는 영문·숫자·`-`·`_` 11자. 그 밖의 주소(채널 주소 · 재생목록만 · 다른 사이트)는 None — 화면이 「유튜브 영상 링크가 아니에요」.
- 허용 범위는 여기서 보지 않는다 — 영상을 가져온 뒤 `check_target`이 본다(링크는 `Source.LINK`).

### 시각

- 한국 시간은 **고정 UTC+9**로 계산한다(서머타임이 없다). 이 PC에는 시간대 데이터베이스가 없어 `ZoneInfo("Asia/Seoul")`이 실패한다 [에이전트].
- `kst_day_range`는 시간대가 없는 `now`를 받으면 `ValueError`. UTC로 받아도 한국 날짜로 자른다.
- `quota_window`: 하루 상한은 이 구간의 게시만 센다 — 서버 · 게시 로봇 · 자동 모드가 모두 이것을 쓴다. 초기화(개발 모드에서만, dashboard 명세)가 오늘 안에 있었으면 그 시각부터, 어제 이전이면 무시하고 오늘 00:00부터. 자정이 지나면 늘 0부터 [사용자].

## 정체성

- 표현 목록에 든 말도 남의 경험을 전해 들은 말 속이면 통과하고, 내 경험이면(남이 함께 나와도) 거부된다 — `기능_댓글검사_목록표현도_전해들은_말이면_통과한다` · `기능_댓글검사_지어낸_후기_표현은_거부된다` · `예외_댓글검사_남과_함께한_내_경험은_지어낸후기다`
- 브랜드 바로 곁의 「직접 겪은」 표현은 지어낸 후기로 거부된다 · 남의 경험을 전해 들은 말 · 앞으로 해 볼 마음은 통과한다 · 브랜드에서 먼 경험 표현은 보지 않는다 — `예외_댓글검사_운명원_곁의_경험표현은_지어낸후기다` · `기능_댓글검사_남의_경험을_전해들은_말은_통과한다` · `경계_댓글검사_운명원에서_먼_경험표현은_보지_않는다`
- 하루 상한은 오늘 안의 마지막 초기화부터 세고, 어제 초기화는 무시한다 — `기능_세는구간_오늘_초기화부터_센다` · `경계_세는구간_어제_초기화는_무시한다`
- 오늘 상한에 닿으면 어떤 영상(테스트 영상 포함)도 통과하지 못한다 — `경계_하루상한_10번째는_허용되고_11번째는_거부된다` · `기능_하루상한_예외영상도_막힌다`
- 「하루」는 한국 시간 자정에서 나뉜다 — `경계_하루구간_한국시간_자정에서_나뉜다`
- 예외가 아닌 영상은 이미 게시했으면 통과하지 못한다 — `기능_영상당1개_이미_게시한_영상은_거부된다`
- 뜨기 직전 영상은 지정 채널 영상이어도 게시를 통과하지 못한다 — `기능_허용범위_뜨기직전_영상은_지정채널이어도_거부된다`
- 링크·해시태그·지어낸 후기가 든 댓글은 통과하지 못한다 — `기능_댓글검사_링크가_있으면_거부된다` · `기능_댓글검사_해시태그가_있으면_거부된다` · `기능_댓글검사_지어낸_후기_표현은_거부된다`
- 게시 버튼 뒤 실패는 재시도하지 않는다 — `기능_재시도_게시버튼_후_실패는_막힌다`
- 사용자가 창을 닫아 취소한 시도는 재시도하지 않는다 — `기능_재시도_취소는_막힌다`
- 불합격 초안이나 초안과 다른 글은 모드와 무관하게 통과하지 못한다 — `예외_초안일치_불합격이거나_글이_다르면_거부된다`
- 채널 게시 스위치가 꺼져 있으면 지정 채널 영상은 통과하지 못하고 테스트 영상만 통과한다(D-34) — `기능_허용범위_채널게시가_꺼지면_테스트영상만_통과한다`
- 재료 없이 보는 검사도 링크·지어낸 후기를 잡는다 — `기능_댓글검사_재료없이_링크와_지어낸후기를_잡는다`
- 유튜브 영상 링크의 여러 꼴에서 같은 id를 뽑고, 영상 링크가 아니면 None — `기능_링크_여러_꼴에서_영상id를_뽑는다` · `예외_링크_영상링크가_아니면_None이다`
- 입출력·시각 읽기·다른 부품 import를 하지 않는다 — `기능_결정론부품_입출력모듈을_불러오지_않는다` · `기능_결정론부품_현재시각을_스스로_읽지_않는다` · `기능_결정론부품_다른_부품을_불러오지_않는다`

## 의존

- 의존하는 것: `models`만.
- 이것에 의존하는 것: 서버 · `draft` · `poster` · `auto`.

## 미정 사항

- `forbidden_phrases` 목록과 `grounding_min_overlap` · `max_similarity`의 처음 값은 2단계에서 실제 초안으로 조정한다.
