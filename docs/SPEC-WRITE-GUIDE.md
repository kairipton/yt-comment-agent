# 명세 작성 가이드

`docs/systems/` 아래 명세를 **새로 쓰거나 꼴을 바꿀 때** 읽는다. 이 문서가 **꼴에 대한 규칙의 주인**이고,
개별 명세는 규칙을 베껴 적지 않고 여기를 가리킨다.

---

## 1. 꼴 고르기

⚠ **기본값은 시스템 하나 = 문서 하나**(`docs/systems/<시스템>.md`)다. 갈라 놓는 것은 값어치가 확인됐을 때만 한다.

| 꼴 | 언제 |
|---|---|
| **단일 문서** | 기본값. 절 제목이 읽는 단위다 |
| **축형(평면)** | 종류가 **나열**될 뿐 상하가 없다. 인덱스 하나 + 형제 잎 |
| **계층형 — 종류**(is-a) | 상위에 올릴 **공통 사실**이 있다 |
| **계층형 — 담김**(has-a) | 부모가 **배치·생명주기**를 진다(화면 칸 → 그 안의 조각) |

**갈라도 되는 조건 셋** — 잎이 여럿이고 **잎마다 고유 규칙이 실제로 있다** · 한 잎을 고칠 때
**다른 잎이 방해가 된다** · 목록의 주인이 될 **설정 목록이나 enum이 있다**.

**갈라선 안 되는 때** — 잎이 하나뿐이다(파일 이름만 바뀐다) · **조상이 잎보다 두껍다**(읽을 양이 오히려 는다).

---

## 2. 단일 문서의 규약

- **절 제목은 남이 부를 이름이다.** 다른 문서는 `guard.md` §하루 상한처럼 절 이름으로 가리킨다.
- **한 절은 그 안에서 끝난다.** 다른 절을 읽어야 뜻이 서면 절이 잘못 갈린 것이다.
- 줄 수는 판정 기준이 아니다. 기준은 **「한 절을 고칠 때 다른 절이 방해가 되는가」**다.

**뼈대**

```markdown
# <시스템 이름>

<책임 한두 줄>

## 구성요소
## 동작
## 정체성
## 의존
## 미정 사항
```

---

## 3. 갈랐을 때의 규약

**계층은 파일명이 진다. 폴더는 서랍일 뿐이다.**

```
docs/systems/post/Post.Step.Typing.md
              └서랍 └──── 체인 ────┘
```

부모는 마지막 마디를 뗀 것(`Post.Step.md`), 조상은 마디를 하나씩 뗀 전부다.

- **파일명 첫 마디 = 폴더 이름.** 폴더가 마디를 나눠 갖지 않는다.
- 잎 하나를 고칠 때는 **조상 체인 전부**를 함께 읽는다.
- 잎에는 **그 하나만의 예외**를 적는다. 없으면 `설정 값 외 예외 없음.` 한 줄로 둔다 —
  빈 잎은 「아직 안 썼다」가 아니라 「예외 없음이 확정됐다」는 뜻이다.
- **형제 전부에 참인 사실은 부모로 올린다.** 기준은 「형제 **전부**에 참인가」이지 「말이 되는가」가 아니다.
- **잎 목록의 주인은 설정 목록이나 enum이다.** 문서가 목록을 따로 갖지 않는다. 트리를 세우면 1:1을 지키는 검사 훅을 함께 세운다.
- ⚠ 기존 명세를 갈라 옮겼으면, 원본을 걷기 전에 **원본의 모든 문단이 어디로 갔는지 대조한다.**

## 4. 정체성 — 테스트 이름을 건다

「없어지면 그 시스템이 아니게 되는 성질」은 `## 정체성` 절에 문장으로 적고 **지키는 테스트 이름을 백틱으로 병기**한다.

```markdown
- 한 영상에는 댓글 하나만 게시된다 — `경계_영상당1개_같은영상_두번째_게시는_거부된다`
```

- `check_identity_anchors.py` 훅이 그 이름이 `tests/`에 실재하는지 매 턴 대조한다.
  문장을 고치려면 테스트도 고쳐야 하고, 그 고침이 diff에 남아 **조용한 성질 변경이 불가능해진다.**
- ⚠ 백틱 속 한글 테스트 이름은 「명세가 부르는 이름」으로 읽힌다. **없는 테스트 이름을 예시로 백틱에 넣지 않는다.**

---

## 5. 명세가 적지 않는 것

명세는 **지금 무엇이 참인가**와 **왜 그것을 못 뒤집나**만 진다.

| 무엇 | 주인 |
|---|---|
| 지금 값(채널·상한·글자 수) | `config.yaml` |
| 바꿀 수 없는 요구 | `docs/PROJECT.md`의 `[요구]` 항목 — 명세는 가리킨다 |
| 결정의 날짜·근거·기각안 | `docs/DECISIONS.md` — 명세는 `D-번호`로 가리킨다 |
| 어느 시스템이 무엇을 쓰나 | `docs/system-map.md` |
| 지금 어디까지 됐나 | `docs/PROGRESS.md` |

⚠ **날짜·경위·근거를 적지 않는다.** 누가 정했는가는 표지 하나로만 밝힌다 —
`[요구]` · `[사용자]` · `[에이전트]`. 경위가 아니라 **권한 표시**다.

⚠ **수를 적지 않는다.** 몇 개인지는 적는 순간 낡는다. 수의 **주인을 가리킨다.**
